# Welcome to Cowbell

Cowbell gives you a world to inhabit and change. You can meet people, build places, and make objects
that respond to what people do. You can also use it as the starting point for a world of your own.

The server, **mooR**, keeps the world running and stores its objects and programs. Cowbell supplies
the starting rooms, objects, commands, and authoring tools. This starting collection is called a
**core**. **Meadow** is a client: an application through which you visit the world. You can also
connect with a terminal client.

This book is for people who visit, build, program, or run a Cowbell world. You do not need to learn
programming before you can build. The programming tutorials introduce code when you need it.

## Choose a starting point

- **Visiting a world:** start with [your first visit](visiting/first-visit.md).
- **Making places and objects:** start with [building](building/index.md), then give your creations
  [rules and reactions](behaviour/rules-reactions-relations.md).
- **Learning to program:** [make a pet rock](programming/pet-rock.md). The lesson explains its code
  as you go.
- **Making characters:** meet [Henri](actors/henri-and-the-cupboard.md), a cat whose reactions you
  can author yourself.
- **Running a world:** start with [the operator's guide](running/index.md). This includes the
  planned chapters on installation, maintenance, and updates through `@changes`.

You can follow these paths separately. A world operator does not have to complete the programming
tutorials before learning how to back up a database. A builder does not have to operate a server.

## Reading the examples

The tutorials show commands alongside their expected output. `%` marks a command to type. Leave out
that marker. `=` marks expected output, and `~~` marks part of a response. Object identifiers and
some other details will differ in your world.

Several tutorials also run as automated tests. Their collapsible test sections prepare accounts or
check results. You can leave those sections closed while following the lesson.

Each tutorial lists the permissions you need. Building, programming, and administration are
different kinds of access. Ask your world's operator if a command is unavailable to you.

## The book is taking shape

The existing tutorials and reference pages are collected here. Entries marked **planned** in the
contents identify chapters that still need to be written. They are not links to finished guides. In
particular, the operator's guide currently provides an outline and pointers to the server manual.

For command help inside a world, type `help`, followed by a topic or command when needed. Each world
can change its objects and commands, so its help may describe additions that are not in this book.
