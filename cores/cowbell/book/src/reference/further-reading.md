# Other manuals and project references

The Cowbell Book explains how to use and extend this core. The
[mooR Book](https://timbran.org/book/2.0-dev/html/) covers the server, the MOO language, database
semantics, and built-in functions. Use it when you need the rules of the language or server
configuration details.

The
[Meadow project page](https://github.com/timbran-project/moor/blob/main/clients/meadow/README.md)
introduces the browser and desktop client, including its object browser and editors.

## Inside the world

Use `help` for available topics, or append the command you need. For example, `help #` explains the
object shortcut command, and `help @changes` introduces the change-review tools.

In-world help can reflect local changes. The book describes Cowbell's supplied objects and commands.

## For core contributors

- [Runtime testing](https://github.com/timbran-project/moor/blob/main/cores/cowbell/RUNTIME_TESTING.md)
  explains the test suites and executable tutorials.
- [Style guide](https://github.com/timbran-project/moor/blob/main/cores/cowbell/STYLE_GUIDE.md)
  describes the conventions for core source.
- [Capability security guide](https://github.com/timbran-project/moor/blob/main/cores/cowbell/CAPABILITIES.md)
  describes permissions and delegated authority for core programmers.
- [Book coverage and writing plan](https://github.com/timbran-project/moor/blob/main/cores/cowbell/book/README.md)
  lists missing chapters, source material, and verification work.

The internal
[rule and reaction data document](https://github.com/timbran-project/moor/blob/main/cores/cowbell/manual/behavior-model.md)
contains both implementation notes and proposed records. Those proposed records are not the current
authoring interface. Use the [reaction guide](../behaviour/reactions.md) for the implemented
commands.
